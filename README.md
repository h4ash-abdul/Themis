# THEMIS - Fraud Inoculation Simulator

[![Live Deployment](https://img.shields.io/badge/Live_Deployment-Visit_Site-00ff00?style=for-the-badge&logo=vercel)](https://themis-azure.vercel.app/)

**THEMIS** is an interactive, multilingual cyber awareness platform designed to inoculate users against modern fraud and manipulation tactics. 

Through voice and text simulators, behavioral profiling, and global threat monitoring, THEMIS prepares users to recognize and combat sophisticated threats.

### 🌐 Live Demo
You can visit the live application here: **[https://themis-azure.vercel.app/](https://themis-azure.vercel.app/)**

---

### Project Structure
- `/frontend` - The Next.js frontend application with brutalist UI, multilingual i18n support, and interactive scroll components.
- `/backend` - The FastAPI backend supporting the simulation logic.
